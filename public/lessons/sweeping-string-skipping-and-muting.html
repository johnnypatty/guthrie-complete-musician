Technique • Weeks 1-24

Sweeping, String Skipping, and Muting

Cross nonadjacent and adjacent strings efficiently while each note remains rhythmically separate and unwanted strings stay silent.

Progressive technique • sweeping • string • skipping • muting

Purpose

Cross nonadjacent and adjacent strings efficiently while each note remains rhythmically separate and unwanted strings stay silent.

Sweep method

  1. Mute the strings and practise a single relaxed rake through two, then three strings.
  2. Add one fretted note per string; release each note as the next sounds so the result is melodic, not a held chord.
  3. Isolate the direction change at the top/bottom. Loop only the last note, turn, and first return note.
  4. Add the smallest useful arpeggio fragment to a real progression.
  5. Move the top note or rhythm so the shape becomes a phrase rather than a stock exercise.

String-skipping method

  1. Pick two notes on nonadjacent strings with the unused middle string muted.
  2. Alternate the starting stroke and travel direction.
  3. Add a fretting-hand shift only after the pick consistently clears the skipped string.
  4. Create an intervallic melody using the skip; sing the contour first.

Muting map

  • Lower-pitched strings: often controlled by picking-hand palm and fretting-hand finger contact.
  • Higher-pitched strings: often controlled by fretting-finger undersides/unused fingers.
  • During taps: picking hand must mute even while leaving the ordinary picking position.
  • With gain: test pauses between notes; silence is part of the phrase.

Success test

At a moderate gained tone, record the phrase and amplify playback. Notes are separated, direction changes stay in time, skipped strings do not speak, and the arpeggio resolves to a musically chosen target.

Common mistake

Practising a large six-string shape before the two-string transition is controlled. Complexity hides the location of the failure.
