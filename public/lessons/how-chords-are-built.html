How Chords Are Built

Chord creation is interval selection plus voicing and context. You never need to wait for a chord dictionary.

Chord creation is interval selection plus voicing and context. You never need to wait for a chord dictionary.

Step 2 — extensions

Continue stacking thirds above 7: 9 is a type of 2, 11 a type of 4, 13 a type of 6.

  • Cadd9 = C E G D: added 9, no 7 required.
  • C9 = C E G Bb D: dominant 7 plus 9.
  • Cmaj9 = C E G B D.
  • Cm9 = C Eb G Bb D.
  • C13 conceptually contains C E G Bb D F A, but guitar voicings normally omit nonessential tones.

Step 3 — identify essential color

  • Third tells major/minor.
  • Seventh distinguishes maj7, dominant, minor, and diminished families.
  • Altered 5/9/11/13 supplies color/tension.
  • Root can be supplied by bass; fifth is often first to omit unless altered.

Step 4 — place it on guitar

Choose a bass note and desired top melody. Find essential tones on a three- or four-string set. Omit duplicated roots/fifths before sacrificing thirds/sevenths/color tones. If another chord tone is lowest, use a slash symbol such as C/E.

Step 5 — connect, do not grab

For the next chord, keep common tones and move other voices the smallest musical distance. Try to make the top note form a melody.

Creation exercise

Build Dm9 without a shape chart:

  1. D minor triad = D F A.
  2. Minor 7 adds C.
  3. Nine adds E.
  4. Choose D or another useful bass.
  5. On three/four upper strings, preserve F, C, E; omit A or duplicated D if necessary.
  6. Move it to G13, preserving common/nearby tones.

Success test

Given any root and common quality, you can spell it, state essential tones, create at least two playable voicings, and explain how each connects to a neighboring chord.
